## Preview locally

Open `index.html` in a browser, or use VS Code's Live Server extension. Keep the folder structure intact so image paths and project links work.

## Add or change project video links

Each project page contains a `Project video / walkthrough` section and an editable button:

- Chair: `projects/project-01.html`
- House: `projects/project-02.html`
- Smartphone: `projects/project-03.html`

Find the project's video button and update its `href` value. The chair and smartphone buttons currently use the Google Drive folder links provided by the artist. The house button uses `href="#"` until its link is supplied.

For public access, set the Drive item's sharing permission to **Anyone with the link — Viewer**. Do not publish private or confidential project files.

## Project downloads

The website has space for project-download links, but no `.blend` source files were provided with the image uploads. If you want to offer downloadable assets, upload only files you own and intend to share, then add links to the relevant project page.

## Publish on GitHub Pages

1. Extract this ZIP.
2. Sign in to https://github.com/ and create a **new public repository** named `overallspace-portfolio`.
3. Upload the contents of this folder into the repository root. Make sure `index.html`, `styles.css`, `script.js`, `services.html`, and `favicon.svg` are at the root, not nested inside another folder.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait for the deployment to finish. Your site should be available at:

   `https://codeware07.github.io/overallspace-portfolio/`

If you choose a different repository name, change the URL accordingly. If the site is not available immediately, check the Pages status and allow a few minutes for deployment.
